# Kobold YipYap
### Ternary Translator & Speech Synth

Kobold YipYap is an interactive client-side web application for transliterating English text into Kobold ternary writing and synthesizing organic audio speech using the Web Audio API.

Created by **nopetrides**.

## Features

- **Ternary Transliteration**: Bidirectional transliteration between English characters and Kobold ternary symbols (`.`, `-`, `:`).
- **Web Audio Speech Synthesis**: Real-time synthesized audio speech for Kobold ternary strings with pitch modulation, speed, and volume controls.
- **Custom Audio Samples**: Import and export custom audio samples or presets.
- **Glyph Renderer**: Interactive connected shape glyph renderer for Kobold symbols.

## Development

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Type-check:
   ```bash
   npm run lint
   ```

4. Build for production:
   ```bash
   npm run build
   ```
